## About the Project

NewsExplorer is a responsive web application that allows users to search for the latest news articles by topic using the NewsAPI. Users can browse search results, view article details, and save articles to their personal account after signing in.

This project was built as my final frontend project for the TripleTen Software Engineering program. It demonstrates working with external APIs, React components, state management, reusable UI, responsive design, and modern frontend development practices.

## Tech Stack

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- NewsAPI
- React Hooks
- Fetch API
- Responsive Web Design
- Git & GitHub

## Features

- Search for news by keyword
- Responsive layout matching a Figma design
- "Show More" pagination for search results
- User authentication modals (login & registration UI)
- Save articles interface (frontend)
- Article cards with publication date, description, source, and image
- Direct links to original news articles
- Clean, component-based architecture

## What I Learned

Building NewsExplorer strengthened my understanding of React and component architecture. I gained experience working with asynchronous API requests, managing application state with hooks, building reusable components, and translating a Figma design into a responsive, production-style interface. It also reinforced best practices for organizing a scalable frontend project using Vite and Git.
